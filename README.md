# Кинопульт

Статическая страница для GitHub Pages. Поиск фильмов и сериалов работает через TMDB с личным Read Access Token пользователя. Токен сохраняется только в `sessionStorage` открытой вкладки. Страница может открыть источник просмотра и запросить загрузку по прямой ссылке на файл. Для сериала можно создать список ссылок на диапазон серий по URL-шаблону.

## Публикация на GitHub Pages

1. Создайте публичный репозиторий и загрузите `index.html` в его корень.
2. Откройте **Settings → Pages → Build and deployment**.
3. Выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`.
4. Откройте адрес, который покажет GitHub Pages.

Данные TMDB не содержат видеофайлов. Для подписочного сервиса вставьте URL страницы, откройте источник и войдите в свой аккаунт там. Статическая страница GitHub Pages не получает cookies или доступ к уже открытой вкладке. Разрешение на загрузку определяет сам сервис. Для внешней прямой ссылки браузер может открыть видео вместо сохранения: это зависит от заголовков сервера и настроек браузера.
